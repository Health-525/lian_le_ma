# 练了吗 (Lian Le Ma)

> 你今天练了吗？

一款 **AI 健身教练 App**。两条核心主线：摄像头动作纠错（首版支持深蹲、弓步蹲、推举、俯卧撑）与真人音色语音鼓励的情绪价值。围绕这两条主线，提供新用户运动评估、7 天训练计划生成、训练中语音命令控制、训练后报告、会员付费墙与分项隐私授权等支撑能力。

## 项目简介

完整的用户旅程：

- **运动评估**：采集训练目标、场地、可用器械、每周频率与伤痛风险自评（敏感健康信息需单独同意）。
- **7 天计划**：基于评估由确定性逻辑生成尊重场地/器械/频率/伤痛情况的训练计划。
- **摄像头动作纠错**：通过稳定契约消费外部动作识别模型的结构化分析结果，转换为面向用户的自然语言纠正建议（模型未就绪期间由桩实现占位，本系统不做生物力学判定）。
- **语音命令**：训练中以固定意图（暂停/继续/换动作/降低难度/再说一遍/结束）控制训练，无需腾手。
- **训练报告**：训练结束生成动作分、风险提示、纠正次数与下一次训练重点。
- **会员付费**：免费次数用尽后展示付费墙，经 Apple IAP 解锁 Pro 权益。
- **隐私授权**：摄像头、麦克风、HealthKit 分项授权，敏感健康信息单独明示同意。

> 设计红线：训练计划、动作分等数值由确定性纯函数产出，绝不由 LLM 生成；LLM 仅用于自然语言文案的生成或润色，且始终有模板兜底。

## 仓库结构 (Monorepo)

本仓库采用 monorepo 组织，分为前后端两个工作区：

| 目录 | 说明 |
|------|------|
| `backend/` | FastAPI + Python 后端服务：业务编排、确定性计算、数据持久化与第三方能力调度。 |
| `app/` | React Native + Expo 移动客户端：评估问卷、训练界面、摄像头与语音采集、音频播放、付费墙与授权管理。 |

详细的需求、设计与实现计划见 `.kiro/specs/fitness-coach-agent/`。
