# 练了吗 (Lian Le Ma)

> 你今天练了吗？

一款运动健身打卡记录应用。

## 项目简介

帮助用户记录每日运动情况，养成健身好习惯。

## 功能规划

- [ ] 用户注册 / 登录
- [ ] 运动打卡记录
- [ ] 运动类型管理
- [ ] 打卡日历视图
- [ ] 运动数据统计
- [ ] 个人成就系统
